JAY ZONE TV — mwongozo wa haraka (Kiswahili)

Yaliyomo:
- index.html: website ya simu yenye muonekano mweusi/kadi mbili kwa mstari.
- Channel za Azam zinafungua huduma ya AzamTV Max.
- Channel nyingine zimeachwa bila link hadi upate URL rasmi iliyothibitishwa.
- Search na filter za Sports/Burudani/Habari zinafanya kazi.

JINSI YA KUIWEKA MTANDAONI KWA BURE KWA ANDROID:
1. Pakua na fungua ZIP hii kwenye simu (Files > Downloads > JAY_ZONE_TV.zip > Extract).
2. Fungua Chrome na nenda https://app.netlify.com/drop
3. Ingia/jiandikishe kwenye Netlify.
4. Netlify Drop inaweza kuhitaji upakie folder ya tovuti. Ikiwa simu hairuhusu kuchagua folder, tumia app ya file manager ku-extract ZIP, au tumia kompyuta.
5. Chagua folder yenye index.html na subiri deployment ikamilike.
6. Netlify itakupa anwani inayoishia netlify.app. Fungua anwani hiyo na ushiriki kwa watu.
7. Kwa kubadilisha website, hariri index.html na upakie tena folder.

KUBADILISHA LINK ZA CHANNEL:
1. Fungua index.html kwenye text/code editor.
2. Tafuta sehemu inayoanza: const channels = [
3. Kwa channel inayokosa link, weka URL rasmi kwenye url:"", kwa mfano url:"https://tovuti-rasmi.example/".
4. Usiongeze link za matangazo ya kulipia au stream isipokuwa una ruhusa ya kusambaza.

KUMBUKA:
- Hosting ya Netlify ina mpango wa bure wenye mipaka ya matumizi; inaweza kusimama ukifikia kikomo cha mwezi.
- Domain ya bure itakuwa subdomain ya Netlify; domain maalum kama jayzonetv.com kwa kawaida hununuliwa tofauti.
- Hii ni website ya link pekee, si huduma ya kutangaza live yenyewe.
